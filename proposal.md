# Title
Digital Color Mixer

## Repository
<https://github.com/JazziBee/final-project.git>

## Description
This program will allow the user to pick two colors from a color picker and output the result of what those two colors would look like mixed. This will act as a digital way to mix colors like you would traditonally on a paint palette and will allow artists to visualize what two colors would look like if they were mixed, which would be helpful in creating a gradient in digital art.

## Features
- Color Picker
	- User will be able to pick two colors from a color wheel and be able to adjust their hue, saturation, and brightness using sliders.
- Chosen Color Display
	- The two colors chosen by the user will be displayed, likely in a box/frame. The colors will update as the user adjusts them in the color wheel and saturation and brightness sliders.
- Mixed Color Display
	- The resulting color from mixing the two colors will be displayed in a third box/frame and will display RGB values and possibly HSB values and hex code.

## Challenges
- I will probably need to learn how to convert color hex codes to RGB.
- I will need to figure out how to get the colors to mix.
- I will need to create a color wheel or some other way of picking the colors to be mixed.

## Outcomes
Ideal Outcome:
- Ideally, the program will output a color picker that two colors can be picked from and mixed to create a new color.

Minimal Viable Outcome:
- I would say the bare essential would be that the program is able to pick colors, display them, and, even if rudimentary, be able to output a color that is a mix of the two colors. I think the minimum outcome would be being able to mix the primary colors.
